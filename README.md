# LNet SPIN

Sitio estatico institucional para LNet Sovereign Public Identity Network.

## Publicacion en GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Agregar el remoto:
   `git remote add origin https://github.com/TU_USUARIO/TU_REPO.git`
3. Hacer el primer commit y push:
   `git add .`
   `git commit -m "Initial site"`
   `git push -u origin master`
4. En GitHub, abrir `Settings > Pages`.
5. En `Source`, elegir `GitHub Actions`.
6. El workflow `Deploy GitHub Pages` publicara automaticamente el sitio.

Cuando termine el workflow, la URL quedara disponible en:

`https://TU_USUARIO.github.io/TU_REPO/`
